# 🎊 Festivals App – Celebrate Every Festival, Smarter 🪔🎉

> 🧑‍💻 **My first React.js project** built with Vite + Tailwind CSS and deployed on **Vercel**
> 🗓️ Know how many days are left for a festival, learn its significance, and even test your knowledge with fun MCQs powered by AI!

---

## 📌 About the Project

**Festivals App** is a fun and informative web app where users can:

✨ **See how many days are left** for upcoming festivals
📚 **Learn the cultural and historical significance** of each festival
❓ **Take AI-generated quizzes** (MCQs) about festivals using **Google Gemini API**
📬 Visit the built-in **Contact Me** and **About Me** sections

It’s a simple, beautiful way to stay connected to celebrations — and it was built as part of my journey into **React development**!

---

## 🚀 Tech Stack

* ⚛️ **React.js** (with **Vite** for blazing fast dev experience)
* 🎨 **Tailwind CSS** (for utility-first and responsive styling)
* 🤖 **Google Gemini API** (for dynamic festival-based quizzes)
* ☁️ **Vercel** (for smooth deployment and hosting)

---

## ✨ Features

* 🧮 Countdown timer to show how many days are left until each festival
* 📖 Description and cultural background of festivals
* 🧠 Interactive **AI-powered festival quiz** section (MCQs)
* 📇 Simple **About Me** and **Contact Me** pages
* 🌐 Fully responsive and mobile-friendly UI
